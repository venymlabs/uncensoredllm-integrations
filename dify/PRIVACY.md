## Privacy

This plugin sends the prompts, model parameters and API key you configure in Dify to the UncensoredLLM API at the base URL you set (by default `https://uncensoredllm.xyz/v1`), and nowhere else. It collects no telemetry and stores nothing itself; Dify keeps the API key in its own encrypted credential store.

UncensoredLLM's own policy: prompts and answers are not stored. See https://uncensoredllm.xyz for the full privacy policy.
