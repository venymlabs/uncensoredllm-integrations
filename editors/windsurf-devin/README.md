# Windsurf (now Devin Desktop)

## Status: blocked

docs.windsurf.com/windsurf/models now redirects to docs.devin.ai/desktop/models (checked 2026-11-23). That page lists only models Devin Desktop provides and says nothing about bring-your-own-key or a custom base URL. There is no setting that points Cascade at an outside OpenAI-compatible endpoint, so there is nothing to configure, import or list.

What would close it: Windsurf/Devin adding a custom OpenAI-compatible endpoint setting. No endpoint on our side helps; the wire format is not the gap.

The Codeium/Windsurf extension for other editors (`Codeium.codeium`, 4.0M installs) has the same limit.
